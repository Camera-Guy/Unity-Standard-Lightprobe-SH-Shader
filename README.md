# Unity-Standard-Lightprobe-SH-Shader
A shader that uses light probe Direction to create a specular highlight to mimic Mixed lighting in Fully baked enviroments

Has Reflection Tint, Fresnel Intencity, Lightprobe SH Tint, Has two detail maps for detail mask A+ and A-, and more options

I made this to compensate for the random quality lighting in VR chat worlds
